# Magistrska naloga — SPD zasteklitev

Analiza energetske učinkovitosti SPD/EC zasteklitve za stekleno poslovno stavbo v Ljubljani.

## Datoteke
- `magistrska-karlsoon_roos.ipynb` — glavni Jupyter notebook z izračuni
- `SVN_LJ_Ljubljana-Bezigrad...epw` — urni vremenski podatki (TMYx)
- `soncno-sevanje_ploskve.xls` — mesečni podatki o sončnem obsevanju (ARSO)
- `test final.xlsx` — meritve SPD stekla
